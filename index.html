n8n-auto-upload

This is a web-based application that allows users to upload video content to TikTok using the official TikTok API.

How it works

  1. User logs in via TikTok OAuth
  2. User provides a video source
  3. The system processes the video
  4. The video is uploaded to TikTok

Features

  • Secure OAuth authentication
  • Video upload via TikTok Content Posting API
  • No permanent data storage
