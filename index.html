n8n-auto-upload

n8n-auto-upload is a web-based application that allows users to upload video content to TikTok using the official TikTok Content Posting API.

How it works

  1. User logs in via TikTok OAuth
  2. User provides a video source
  3. The system processes the video
  4. The video is uploaded to TikTok

Features

  • Secure OAuth authentication
  • Video publishing via official API
  • No permanent data storage
